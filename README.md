# Vedic Matters Research

Open-access, source-led research on Indian knowledge systems published by [Vedic Matters](https://vedicmatters.com/research).

This repository preserves readable manuscripts, versioned PDFs, citation metadata, licences, and links to the canonical publication records. It is intended to improve transparency, reproducibility, correction, and scholarly citation. These papers have not undergone external academic peer review unless a publication record explicitly states otherwise.

## Citation

Use the version DOI when citing the exact PDF you consulted. Use the concept DOI when a citation should resolve to the newest Zenodo version. Machine-readable citation metadata is provided in [`CITATION.cff`](CITATION.cff), and publication-specific BibTeX entries are in [`citations.bib`](citations.bib).
